# Лабораторна робота 7 - Список справ 2

## Як запустити
1. Створіть Firebase Realtime Database.
2. Скопіюйте URL бази даних і додайте `/todos.json`.
3. Відкрийте `script.js` і замініть значення `FIREBASE_URL` на своє посилання.
4. Запустіть `index.html` через Live Server або відкрийте файл у браузері.

## Реалізовано
- POST: додавання справи до Firebase.
- GET: читання всіх справ з Firebase.
- PATCH: зміна статусу виконання справи.
- DELETE: видалення справи.
- Умовний рендеринг завантаження та помилок.
